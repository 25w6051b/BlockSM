# BlockSM Demo

This project is designed for easy local execution of the demo.

## Required Environment
- Java: Eclipse Temurin JDK 8.0.412.8

## Execution Steps
1. Run `run-demo.bat` to start the Spring Boot application.
2. Open `starter-code/index.html` in your browser to view the frontend interface.

## Customization
By modifying the definitions in `json/predefined.json`, you can generate corresponding modeling element blocks.

## Caution
This application uses port `8080`.  
If another process is already using this port, please either change the port number or stop the conflicting process.
